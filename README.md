# Creative Studio

Starter project built with React, TypeScript, and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Pages

- `/` — Homepage
- `/studio` — Studio
- `/work` — Work
- `/about` — About us
- `/contact` — Contact us
- `/journal` — Journal

Animation and 3D dependencies are installed and ready to use: GSAP, Framer Motion, Lenis, Three.js, React Three Fiber, and Drei.
